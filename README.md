# 🎬 YouTube Ad Revenue Prediction & Streamlit Web App

## 📘 Project Objective
Develop a **Regression–based predictive model** to accurately estimate **YouTube ad revenue** for individual videos using performance and contextual metrics.  
Integrate the trained model into an **interactive Streamlit web app** for real-time revenue forecasting and data-driven content strategy.

---

## 🎯 Scope of Work
- Perform **data preprocessing, feature engineering, and exploratory data analysis (EDA)** to prepare the dataset for modeling.  
- Train and evaluate regression models using metrics such as **R², RMSE, and MAE**.  
- Deploy the optimized model in a **Streamlit application** featuring **visual analytics** for interpreting revenue predictions and identifying key performance drivers.

---

## 🧰 Tools & Technologies

### 🐍 Programming & Data Processing
- **Python** – Core programming language for data analysis and modeling.  
- **pandas** – Data manipulation, cleaning, and transformation.  
- **scikit-learn** – Machine learning algorithms, KNN imputation, and predictive modeling.  

### 📊 Data Visualization & Reporting
- **Matplotlib** & **Seaborn** – For exploratory data analysis (EDA) and static visualizations.  

### 🗄️ Data Storage & Management
- **SQL** – For scalable data querying, integration, and storage management.  

### 🌐 Deployment
- **Streamlit** – Lightweight web framework (Python + React) to turn scripts into interactive web applications.  

---

## ⚙️ Key Features
- Predict YouTube ad revenue for individual videos based on key performance indicators.  
- Handle missing data and outliers using **data preprocessing pipelines**.  
- Generate **interactive dashboards** with performance metrics and model insights.  
- Simple, clean **Streamlit interface** for users to input video parameters and view predicted revenue.  

---

## 📈 Regression Models Implemented
- K-Nearest Neighbors (KNN)
- Decision Tree Regressor
- Random Forest Regressor
