# Content-Monetization-Modeler
Develop a Regression–based predictive model to accurately estimate YouTube ad revenue for individual videos using performance and contextual metrics. Integrate the trained model into an interactive Streamlit web app for real-time revenue forecasting and data-driven content strategy
SCOPE OF WORK
The project involves data preprocessing, feature engineering, and exploratory data analysis (EDA) to prepare the dataset, followed by model training and evaluation using regression metrics (R², RMSE, MAE).
